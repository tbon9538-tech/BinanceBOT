## 2. 研究集结果（最终配置）

| 指标 | 最终配置 | BTC 持有 | BTC 趋势（同一过滤） |
|---|---|---|---|
| 年化 | 50.3% | 63.4% | 75.1% |
| 夏普 | 1.68 | 1.10 | 1.45 |
| 最大回撤 | −26.9% | −76.6% | −43.1% |
| Calmar | 1.87 | 0.83 | 1.74 |
| 前 / 后半段夏普 | 2.24 / 1.15 | 0.87 / 1.52 | 1.44 / 1.48 |

- 成本 ×2：夏普 1.61、最大回撤 −28.1%（E9）。资金 500 USDT：年化 49.8%（E9）。
- walk-forward（只在目标波动与核心权重上选择）：拼接样本外年化 35.0%、夏普 1.43、最大回撤 −23.2%。
- block bootstrap 最大回撤：中位数 −25.8%，80 分位 −32.1%，95 分位 −40.0%；回撤 ≤ 35% 的概率 87%。
- DSR = 0.998（试验数 107，试验夏普标准差 0.18）。注意 DSR 检验的是"夏普显著大于 0"，其中包含加密市场本身的上涨（beta），不等于选币有 alpha。

## 3. 为什么要打折看这些数字

1. **大盘过滤参数处在局部高点**（E2a）：默认值所在 3×3 邻域的 Calmar 均值只有 1.23，低于全网格最优的 80%。按全网格平均水平，夏普约 1.3、Calmar 约 1.15。
2. **样本期包含两段很难重复的行情**：2020～2021 年山寨季、2023～2024 年 BTC ETF 行情。
3. **试验次数**：107 次试验中挑选，Harvey–Liu 的经验做法是对夏普打五折左右。
4. 目标波动 0.35 是按"回撤 80 分位 ≤ 35%"的规则取的上限值，**没有安全余量**；样本外回撤更可能落在 30%～40%。

**现实预期（样本外，完整牛熊周期）**：年化 20%～35%，最大回撤 30%～40%，夏普 0.8～1.2。这与 `strategy_review.md` §6 的判断一致，只是因为目标波动从 0.30 提高到 0.35，收益和回撤的区间都相应上移。

**更保守的备选**：把两个袖子的目标波动改回 0.30（研究集：年化 43.8%、最大回撤 −23.6%、bootstrap 80 分位 −28.0%）。如果用户更看重"回撤 ≤ 30%"这个目标，建议采用备选值；只需修改 `config.yaml` 中的两个 `target_annual_vol`。
