## 实验结论

（按运行顺序追加）

### E0 引擎交叉校验（2026-11-01）
- 结果：`v2_replica` 年化 32.1%、夏普 1.14、最大回撤 −43.6%、前后半段夏普 1.81 / 0.50，与探索脚本（review §5.3）**逐项一致**；四个基准（BTC 持有 63.4%、BTC 趋势 75.1% 等）也与探索脚本一致。
- v3 默认：年化 39.3%、夏普 1.58、最大回撤 −24.3%、Calmar 1.61、前后半段夏普 2.13 / 1.06。
- 结论：**通过**。正式引擎与独立实现一致；v3 默认作为后续实验的基线。
- 观察：v3 默认的卫星袖子平均每月约 63 笔交易（每日平滑 + relative 容忍带），年换手只有 7.1 倍，说明每笔金额小。留待 E8/E9 检验在小资金下的影响。
- 试验数累计：2

### E1 标的池（2026-11-01）
- 11 个变体：Calmar 1.50～1.76，夏普 1.51～1.66，最大回撤 −21.5%～−25.1%，前后半段夏普全部在 1.9～2.3 / 1.0～1.2。
- 默认（30、500 万）Calmar 1.61，所在邻域最低 1.50，全网格最优 1.76 的 80% 为 1.41 → **邻域稳健**。
- 规模 20 的 Calmar 更高（1.76），来自回撤更小，但前半段夏普更低（1.93 对 2.13），两段不一致；规模 40 的夏普略高（1.66），差异 < 0.1，属于噪声。
- 结论：**保留默认值**（标的池前 30、绝对下限 500 万、上市 90 天）。不改配置。
- 试验数累计：13

### E2a 大盘过滤 SMA × 缓冲带（2026-11-01）
- Calmar 热力图（行：SMA，列：缓冲 0 / 1% / 2% / 3% / 5%）：
  - SMA50：1.31 / 1.23 / 1.14 / 0.95 / 0.76
  - SMA75：0.89 / 0.89 / 0.85 / 0.81 / 0.80
  - SMA100：1.22 / 1.36 / **1.61** / 1.70 / 1.24
  - SMA150：1.53 / 1.39 / 1.26 / 1.21 / 1.28
  - SMA200：0.86 / 0.79 / 0.83 / 0.83 / 1.14
- 预注册标准：默认值所在 3×3 邻域（SMA 75～150 × 缓冲 1%～3%）的 Calmar 均值 1.23，**低于**全网格最优（1.70）的 80%（1.36）→ **未通过**。默认值位于局部高点，有一部分是运气。
- 绝对稳健性：25 个格子的夏普全部 ≥ 1.05、Calmar 全部 ≥ 0.76、最大回撤全部 ≤ 36.5%，没有任何一格失效；大盘过滤"有用"这一结论是稳健的，"100 / 2% 最好"这一结论不稳健。
- 结论：按 dev_plan §4 第 2 条，**不选最优点，保留默认值**（100 / 2%）；同时把样本内业绩预期下调为全网格均值水平（夏普约 1.3、Calmar 约 1.15），写入参数提案。"多周期均线集成"列为后续研究的第一优先（可降低对单一均线的依赖），本轮不追加未预注册的变体。
- 试验数累计：38

### E2b 替代大盘信号：BTC 时间序列动量（2026-11-01）
- TSMOM 60 / 90 / 120：Calmar 1.06 / 0.79 / 1.41，夏普 1.30 / 1.02 / 1.37，前半段夏普 1.59 / 1.19 / 1.89，均低于 SMA 默认值（1.61 / 1.58 / 2.13）。
- 结论：**不替换**。趋势过滤本身有效（三者都盈利且回撤 < 30%），但不比 SMA 更好；也说明大盘过滤的具体形式对结果有一定影响（与 E2a 一致）。
- 试验数累计：41

### E8 调仓时点与容忍带（2026-11-01）
- 平滑 1 / 3 / 7 天：Calmar 1.19 / 1.47 / 1.87，最大回撤 −37.5% / −32.1% / −26.9%。
- 单一调仓日（周一～周日）：Calmar 1.35 / 1.42 / 1.97 / **3.22** / 1.85 / 1.02 / 1.22，夏普 1.28～1.98——时点运气极大（周四的 3.22 是运气，不能选）。7 日平滑消除了这种离散 ✓。
- 容忍带（卫星每月交易笔数 / 平均每笔金额 / 相对"无容忍带"的跟踪误差 / 总成本占初始资金）：
  - absolute 0.02：19.6 笔 / 91 USDT / 0.035 / 0.25；夏普 1.58、Calmar 1.71
  - relative 0.15：86.1 笔 / 34 USDT / 0.014 / 0.37；夏普 1.61
  - relative 0.25：69.9 笔 / 41 USDT / 0.024 / 0.36；夏普 1.68、Calmar 1.87
  - relative 0.40：52.9 笔 / 53 USDT / 0.039 / 0.35；夏普 1.72、Calmar 2.14
  - 无容忍带：176 笔 / 18 USDT / 0 / 0.42；夏普 1.57
- 用户的判断得到证实：绝对阈值 0.02 让卫星约 3/4 的调整被跳过（每月 20 笔对 70 笔），跟踪误差更大。各容忍带的夏普差 ≤ 0.14、两段方向不一，属于噪声 → 按预注册规则**选 relative 0.25**（跟踪误差居中、成本与 0.40 相当）。
- 结论：保留 `smoothed` 7 天与 `threshold_mode: relative`、`threshold_rel: 0.25`。
- 试验数累计：100

### E10 稳健性汇总（2026-11-01，最终配置）
- walk-forward（训练 12 个月 / 测试 3 个月，9 个候选：目标波动 {0.25,0.30,0.35} × 核心权重 {0.3,0.5,0.7}）：拼接样本外年化 35.0%、夏普 1.43、最大回撤 −23.2%、Calmar 1.51（切换成本忽略）。
- block bootstrap（块长 30 天，1000 次）：回撤中位数 −25.8%，80 / 90 / 95 分位 −32.1% / −36.3% / −40.0%；回撤 ≤ 35% 的概率 87%，≤ 30% 的概率 72%。

- 结论：最终配置见 `doc/research/proposal_v1.md`。

## R8 预注册：山寨季过滤（2026-11-02，在任何 R8 代码编写、任何 R8 实验运行之前写下）

- **背景**：用户 2026-11-02 选择 Q16 方案 B（D-085），研究集扩展为 2020-01-01 ～ 2026-10-31。R2～R4 都没能改进当前配置。
- **纪律**：
  - 只用新研究集（2020-01-01 ～ 2026-10-31）；**2026-11-01 之后是新保留集**，研究命令读不到；
  - 按 D-085，必须同时报告两段：**段 A** 2020-01-01 ～ 2025-06-30、**段 B** 2025-07-01 ～ 2026-10-31（原保留集，熊市）；
  - 试验计入 `trials.csv`；任一试验夏普 > 3 或曲线异常平滑，停下汇报。
  - **如实说明想法的来源**：这个假设部分来自已经看到的数据——当前配置在段 B 几乎不赚钱，同期前 10 等权组合（−24.8%）跑输 BTC 持有（−20.7%）；研究集里也观察到卫星在 2022 年 10 月之后表现变差。正因为想法受数据启发，通过标准要求两段都不变差，而且通过之后仍必须经前向数据检验。
- **假设与经济学理由**：加密币的横截面动量集中在牛市和资金流向山寨币的阶段（strategy_review 中的文献摘要）。当资金从山寨币流回 BTC（山寨币整体跑输 BTC）时，只做多的山寨动量组合大概率亏损，而且风险比 BTC 高。只在山寨币整体跑赢 BTC 时开卫星，应当减少这些阶段的亏损和回撤。
- **方法（事先固定）**：
  - 山寨篮子：d 日卫星袖子的标的池（与现在相同的规则：成交额排名前 30、上市 ≥ 90 天、资产审核近似、排除 BTC），取其中在 [d − N, d] 内收盘价完整的币，**等权**平均它们的 N 日收益；
  - 山寨季：篮子 N 日收益 > BTC 的 N 日收益；参与计算的币少于 5 个时视为不是山寨季；
  - 不是山寨季时，卫星当天的原始目标为空（这一半资金持有 USDT，**不**挪给 BTC），按 7 天平滑逐步退出；是山寨季时卫星规则完全不变；
  - 大盘过滤、核心袖子、其余规则全部不变；新增配置项 `sleeves.satellite.alt_season_lookback`（缺省为空，表示不过滤，即当前行为）。
- **主方案（事先指定）**：N = 60。
- **网格**（定义见 `experiments.yaml` 的 R8a、R8b）：R8a 为 N ∈ {30, 60, 90} 3 个，外加主方案成本 ×2 1 个；R8b 为当前配置 1 个（对照）。合计 5 个试验。
- **两段指标的算法**：每个试验只在整个研究窗口上回测一次，把同一条单位净值曲线在 2025-07-01 切开，分别计算段 A、段 B 的夏普、最大回撤、Calmar。
- **通过标准（全部满足才算通过）**：
  1. 稳健：R8a 中 N = 30 / 60 / 90 三个方案在整个窗口上的 Calmar 最小值 ≥ 三者均值的 80%；
  2. 水平：三个方案整个窗口的 Calmar 均值和夏普均值，分别不低于对照组；
  3. 两段：主方案在段 A 和段 B 的夏普，分别不低于对照组在同一段的夏普（按 D-085，两段都不得变差）；
  4. 成本：主方案成本 ×2 时，在整个窗口上满足 spec §1.1 硬约束（最大回撤 ≤ 35%、夏普 ≥ 0.8、Calmar ≥ 0.6、BTC 年跌幅超过 30% 的年份亏损 ≤ BTC 同期亏损的 1/3）。
  - 观察项（不影响是否通过）：山寨季天数占比、卫星实际持仓天数、换手率的变化；段 B 的回撤变化。
- **通过时**：**不修改 `config/config.yaml`**。主方案成为候选，在新保留集（2026-11-01 之后的前向数据，至少 6 个月）上与当前配置比较夏普和 Calmar，都不低于当前配置才替换。
- **未通过时**：保持当前配置，结论写入本日志。

### R8 结论（2026-11-02，新研究集 2020-01-01 ～ 2026-10-31，代码 7d3d214）
- 对照组（当前配置，R8b）：整个窗口夏普 1.45、Calmar 1.45、最大回撤 −26.9%；段 A 夏普 1.68（与旧研究集结果一致），段 B 夏普 0.22、年化 +2.3%、回撤 −22.4%。
- R8a 山寨季过滤 N = 30 / 60 / 90：整个窗口 Calmar 1.02 / 1.12 / 1.44（均值 1.19），夏普 1.27 / 1.27 / 1.40（均值 1.31）；主方案（60）段 A 夏普 1.51、段 B 夏普 0.02（年化 −1.2%）。
- 逐条判定：
  1. 稳健（Calmar 最小值 1.02 ≥ 均值 1.19 × 80% = 0.95）✅；
  2. 水平（Calmar 均值 1.19 **<** 对照 1.45；夏普均值 1.31 **<** 对照 1.45）❌；
  3. 两段（段 A 1.51 **<** 1.68；段 B 0.02 **<** 0.22）❌；
  4. 成本 ×2（最大回撤 −27.9%、夏普 1.20、Calmar 1.01；2022 年 −13.6%，BTC −64.2% 的 1/3 为 −21.4%；其他年份 BTC 跌幅都没有超过 30%）✅。
- 结论：**未通过（第 2、3 条），不采用**。`config/config.yaml` 不变；`alt_season_lookback` 作为研究选项保留在代码中，默认不启用。
- 观察项：卫星有仓位的天数占比——对照 59%（段 A 63%、段 B 41%），N = 60 为 49%（段 A 51%、段 B 40%）。过滤砍掉的主要是段 A 里本来赚钱的卫星持仓；段 B 里大盘过滤已经让卫星大部分时间空仓，山寨季过滤几乎没有额外作用，反而在少数持仓的日子里错过了反弹。与假设相反，主方案在**两段都变差**，包括本想改善的段 B。
- 观察（不作为改参依据）：山寨篮子相对 BTC 的 N 日表现是滞后信号——山寨币已经跑输一段时间后才关掉卫星，跑赢一段时间后才重新打开，与卫星本身的 21 日动量排序高度重叠，没有提供新信息。
- 试验数累计：144（R8a 4 个、R8b 1 个）。

## R7 预注册：空仓 USDT 理财收益估算（2026-11-02，在任何 R7 代码编写、任何 R7 实验运行之前写下）

- **背景**：当前策略是"一个因子、两个仓位"，大部分时间空仓（新研究集上平均仓位约 0.31）。用户 2026-11-02 要求把它优化成真正的组合策略；闲置 USDT 放活期理财是最简单、与趋势无关的收益来源（ROADMAP R7、功能线 F5）。
- **性质**：这是**估算**，不是在挑参数。收益率是假设值（允许的数据源里没有币安理财的历史利率），结果只回答"值不值得去做 F5 接口验证和实盘实现"。
- **方法（事先固定）**：回测中，每天开始时，前一天收盘后持有的现金按 `(1 + y)^(1/365) − 1` 计息（按日复利）；持仓的币不计息；不考虑申购赎回延迟、额度上限和利率变化；其余规则全部不变。新增配置项 `backtest.cash_yield_annual`（缺省 0，即当前行为）。
- **网格**（`experiments.yaml` 的 R7）：y ∈ {0, 0.02, 0.04, 0.06}，共 4 个试验，y = 0 为对照。研究窗口 2020-01-01 ～ 2026-10-31，同时报告段 A、段 B（D-085）。
- **决策规则**：y = 0.04 时，若整个窗口年化收益至少提高 2 个百分点，且段 A、段 B 的夏普和 Calmar 都不低于 y = 0，则进入 F5（接口验证：demo / testnet 是否支持活期理财申购赎回，以及与先卖后买流程的衔接），否则不做。
- **风险说明**：理财有平台风险，利率随市场变化（牛市高、熊市低），回测里的固定利率会高估熊市阶段的收益。

### R7 结论（2026-11-02，新研究集 2020-01-01 ～ 2026-10-31，代码 b5c41ea）
- y = 0 / 2% / 4% / 6%：整个窗口年化 39.1% / 40.6% / 42.4% / 44.1%，夏普 1.45 / 1.49 / 1.54 / 1.58，Calmar 1.45 / 1.64 / 1.74 / 1.83，最大回撤 −26.9% / −24.7% / −24.4% / −24.1%。
- y = 4% 与 y = 0 对比：段 A 夏普 1.77 对 1.68、Calmar 2.20 对 1.87；段 B 夏普 0.37 对 0.22、Calmar 0.26 对 0.10、年化 5.4% 对 2.3%。
- 决策规则判定：年化提高 3.3 个百分点（≥ 2）✅；两段的夏普和 Calmar 都不低于 y = 0 ✅。**进入 F5（接口验证）**。`config/config.yaml` 不变（`cash_yield_annual` 只用于回测）。
- 说明：这是机械性的估算，增益来自闲置现金的利息，不是预测能力；空仓越多（如段 B 熊市）帮助越大。实际利率随市场变化，熊市往往更低，回测里的固定利率会高估段 B 的增益。理财还有平台风险。
- 试验数累计：148（R7 4 个；它们是估算，不是选参，DSR 计算时可单独说明）。

## R10 预注册：资金费率套利袖子，以及它与当前策略的组合（2026-11-02，在任何 R10 代码编写、任何 R10 数据下载与实验运行之前写下）

- **背景**：用户 2026-11-02 要求"立即优化组合策略"。当前策略是"一个因子、两个仓位"（都赌 BTC 趋势）；期现对冲赚资金费不赌涨跌，是与之互补的收益来源（ROADMAP 阶段 2）。**本研究只做回测**，不改交易代码；实盘要用永续合约，违反项目"不用合约"的基本约束，是否启用由用户决定（Q13）。
- **数据**：data.binance.vision 的 U 本位永续资金费率（`futures/um/monthly/fundingRate`）与永续日线（`futures/um/monthly/klines/*/1d`），2026-11-02 已确认可下载（BTC 从 2020-01 起）。下载与读取都截止到 2026-10-31，2026-11-01 之后属于新保留集，研究代码不读。现货日线用 `market.db`。
- **方法（事先固定）**：
  - 标的：BTCUSDT、ETHUSDT 各占套利袖子资金的一半；
  - 仓位：现货多头与永续空头名义相等；永续杠杆 2（保证金 = 名义 / 2），袖子资金 C 中现货名义 = C / 1.5，其余为永续保证金；
  - 开平仓规则：t 日收盘时，过去 7 天平均资金费率（年化）高于门槛 h 则 t+1 日持有对冲，否则空仓（持有 USDT）。h ∈ {一直持有, 0%, 5%, 10%}，主方案 h = 5%；
  - 收益：持有期间每天收到（或支付）当天全部资金费 × 永续名义；加上期现价差变化（现货日收益 − 永续日收益）× 名义；
  - 成本：每次开仓或平仓，两条腿都计成本：现货 0.1% + 0.05%，永续 0.05% + 0.05%；对冲比例偏离的日常再平衡忽略（简化，会略微低估成本）；
  - 爆仓检查：用永续日线最高价检查空头，任一天相对前一天收盘上涨超过 45%（杠杆 2 下接近爆仓）就记一次爆仓事件，按损失全部保证金计算（研究期内预计不会出现，但要检查）；
  - 组合：组合 = (1 − w) × 当前策略（闲置现金按 4% 计息，R7）+ w × 套利袖子，w ∈ {0.3, 0.5}，主方案 w = 0.5；每天按目标比例再平衡（忽略这部分成本，简化）。
- **试验**：套利袖子 4 个（h 的 4 个取值）+ 组合 2 个（主方案 h 下 w 的 2 个取值）+ 对照 1 个（当前策略 + 4% 闲置计息，即 R7 的 y4）；合计 7 个，计入 `trials.csv`。研究窗口 2020-01-01 ～ 2026-10-31，同时报告段 A、段 B。
- **通过标准（全部满足才算通过）**：
  1. 套利袖子本身：主方案（h = 5%）在段 A 和段 B 扣除成本后的年化收益都为正，且整个窗口最大回撤不超过 10%，研究期内没有爆仓事件；
  2. 稳健：四个 h 取值中，至少三个在两段的年化收益都为正；
  3. 组合改善：主方案组合（w = 0.5）在段 A 和段 B 的夏普都不低于对照；整个窗口最大回撤不比对照更深；
  4. 成本：主方案组合在两条腿成本都翻倍时，仍满足第 3 条的夏普要求。
- **通过时**：不改 `config/config.yaml`，不写交易代码。结论交给用户做 Q13 决策（是否接受合约、账户与资金分配）；接受后才进入工程实现（合约账户、对冲执行器、保证金风控），并且先在合约 testnet / demo 上运行。
- **未通过时**：结论写入本日志，阶段 2 暂缓。
