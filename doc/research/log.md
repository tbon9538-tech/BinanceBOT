## 预注册（2026-11-01，任何正式实验运行之前写下）

基线 = spec v3 的默认配置（`config/config.yaml`）。网格定义见 `doc/research/experiments.yaml`，预算约 115 个配置（上限 150）。

| 编号 | 假设与经济学理由 | 网格 | 通过标准 |
|---|---|---|---|
| E0 | 正式引擎按 v2 规则复现探索脚本的结果（年化 32%、夏普 1.14、回撤 −44%）；差异来自口径（上市天数、排除名单、成本细节） | v3 默认、v2 复刻 | 差异可逐项解释 |
| E1 | 流动性越好的币，动量越可靠、操纵越少；但池子太小时分散不足。按排名取池子在 20～40、下限 0～1000 万之间应当平稳 | 规模 {20,30,40} × 下限 {0,500 万,1000 万}；上市 {60,180} | §0.3 |
| E2a | 趋势择时的价值在于避开深度熊市；均线周期在 50～200、缓冲 0～5% 之间都应有效 | SMA {50,75,100,150,200} × 缓冲 {0,1%,2%,3%,5%} | 默认值 3×3 邻域 Calmar 均值 ≥ 全网格最优的 80%；**不选最优点** |
| E2b | 时间序列动量（价格相对 N 天前）是均线的近亲，效果应相近 | TSMOM {60,90,120} | 满足 §0.3 全部条件才替换 |
| E2c | 逐步建仓更抗 whipsaw，但会错过 V 形反转的起点；预计差异在噪声内 | ramp / immediate | 噪声内选 ramp |
| E3a | 加密横截面动量集中在 1～4 周（LTW 2022、Dobrynskaya） | 回看 {14,21,28,42} | 只在 {21,28} 中选，除非 14 在两段与邻域都明显占优 |
| E3b | 大币呈现短期动量而非反转（Zaremba 2021、Fičura 2023），跳过最近几天没有好处 | skip {0,1,3,5} | §0.3（简化类：skip=0 为更简单） |
| E3c | 除以波动率能降低高波动币的权重偏差；多周期得分更稳（Fieberg 2025） | {ret/vol, ret, blend} | 替换为 blend 必须两段都不变差 |
| E5 | 剔除短期暴涨（拉盘、操纵）有经济学理由；阈值应当不敏感 | {关闭,1.0,1.5,2.0,3.0} | §0.3 |
| E6 | 已有大盘过滤 + 单币均线 + 平滑 + 波动率目标时，止损的边际价值有限（Kaminski–Lo 2014） | 关闭；ATR {2,2.5,3,4}；冷却 {3,14} | 满足 §0.3，且最差 7 日损失明显改善，才开启 |
| E4a | 目标波动由风险约束决定，不按收益选择 | {0.20,0.25,0.30,0.35,0.40} | 选"bootstrap 回撤 80 分位 ≤ 35%"的最大值 |
| E4b | 波动率估计窗口 20～60 天差别不大 | 核心 vol_lookback {20,30,60} | §0.3 |
| E4c | 山寨高度相关，持有 3～8 个差别不大；等权最简单 | top_n {3,5,8} × {等权, 波动倒数} | 噪声内保留 5 个等权 |
| E7 | BTC 趋势与山寨动量在不同阶段各有优势，组合更稳（review §5.4） | 核心 {0,0.3,0.5,0.7,1.0} | 核心 0.5 的前后半段最小夏普 > 两端较小者，且 0.3～0.7 为高原；噪声内用 0.5 |
| E8 | 平滑降低时点运气；relative 容忍带更适合小权重的卫星 | 平滑 {1,3,7}、周一～周日、容忍带 {abs 0.02, rel 0.15/0.25/0.40, 无} | 平滑的离散度明显小于单一调仓日；容忍带：成本相当时选跟踪误差小的，噪声内选 rel 0.25 |
| E9 | 成本 ×2 仍满足硬约束；500 USDT 小资金的颗粒度损失可接受 | 成本 ×1/×2/×3；资金 {500,2000} × {真实,理想} | 成本 ×2 满足 spec §1.1；500 USDT 与理想的年化差 < 2 个百分点 |
| E10 | 汇总：DSR（试验数 = trials.csv 行数）、walk-forward、block bootstrap | WF 候选 9 个 | DSR > 0.9 强、0.5～0.9 弱 |

**明确不做的变体**（不计入试验数，原因如下）：
- 市场广度过滤（E2b 原计划之一）：没有找到加密领域的文献依据（review §4），并且广度依赖每日标的池，会引入额外的循环依赖与复杂度。推迟到后续研究。
- "距 N 日最高价"得分、成交量确认（E3c/E3d 原计划之一）：在基础信号未被否定之前，不增加新的信号维度，控制试验次数。推迟到后续研究。
- EWMA 波动率（E4b 原计划之一）、核心资产 BTC+ETH（E7 原计划之一）：需要新增代码路径，且没有先验证据表明必要。推迟到后续研究（spec §16）。
