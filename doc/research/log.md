## 实验结论

（按运行顺序追加）

### E0 引擎交叉校验（2026-11-01）
- 结果：`v2_replica` 年化 32.1%、夏普 1.14、最大回撤 −43.6%、前后半段夏普 1.81 / 0.50，与探索脚本（review §5.3）**逐项一致**；四个基准（BTC 持有 63.4%、BTC 趋势 75.1% 等）也与探索脚本一致。
- v3 默认：年化 39.3%、夏普 1.58、最大回撤 −24.3%、Calmar 1.61、前后半段夏普 2.13 / 1.06。
- 结论：**通过**。正式引擎与独立实现一致；v3 默认作为后续实验的基线。
- 观察：v3 默认的卫星袖子平均每月约 63 笔交易（每日平滑 + relative 容忍带），年换手只有 7.1 倍，说明每笔金额小。留待 E8/E9 检验在小资金下的影响。
- 试验数累计：2

### E1 标的池（2026-11-01）
- 11 个变体：Calmar 1.50～1.76，夏普 1.51～1.66，最大回撤 −21.5%～−25.1%，前后半段夏普全部在 1.9～2.3 / 1.0～1.2。
- 默认（30、500 万）Calmar 1.61，所在邻域最低 1.50，全网格最优 1.76 的 80% 为 1.41 → **邻域稳健**。
- 规模 20 的 Calmar 更高（1.76），来自回撤更小，但前半段夏普更低（1.93 对 2.13），两段不一致；规模 40 的夏普略高（1.66），差异 < 0.1，属于噪声。
- 结论：**保留默认值**（标的池前 30、绝对下限 500 万、上市 90 天）。不改配置。
- 试验数累计：13

### E2a 大盘过滤 SMA × 缓冲带（2026-11-01）
- Calmar 热力图（行：SMA，列：缓冲 0 / 1% / 2% / 3% / 5%）：
  - SMA50：1.31 / 1.23 / 1.14 / 0.95 / 0.76
  - SMA75：0.89 / 0.89 / 0.85 / 0.81 / 0.80
  - SMA100：1.22 / 1.36 / **1.61** / 1.70 / 1.24
  - SMA150：1.53 / 1.39 / 1.26 / 1.21 / 1.28
  - SMA200：0.86 / 0.79 / 0.83 / 0.83 / 1.14
- 预注册标准：默认值所在 3×3 邻域（SMA 75～150 × 缓冲 1%～3%）的 Calmar 均值 1.23，**低于**全网格最优（1.70）的 80%（1.36）→ **未通过**。默认值位于局部高点，有一部分是运气。
- 绝对稳健性：25 个格子的夏普全部 ≥ 1.05、Calmar 全部 ≥ 0.76、最大回撤全部 ≤ 36.5%，没有任何一格失效；大盘过滤"有用"这一结论是稳健的，"100 / 2% 最好"这一结论不稳健。
- 结论：按 dev_plan §4 第 2 条，**不选最优点，保留默认值**（100 / 2%）；同时把样本内业绩预期下调为全网格均值水平（夏普约 1.3、Calmar 约 1.15），写入参数提案。"多周期均线集成"列为后续研究的第一优先（可降低对单一均线的依赖），本轮不追加未预注册的变体。
- 试验数累计：38

### E2b 替代大盘信号：BTC 时间序列动量（2026-11-01）
- TSMOM 60 / 90 / 120：Calmar 1.06 / 0.79 / 1.41，夏普 1.30 / 1.02 / 1.37，前半段夏普 1.59 / 1.19 / 1.89，均低于 SMA 默认值（1.61 / 1.58 / 2.13）。
- 结论：**不替换**。趋势过滤本身有效（三者都盈利且回撤 < 30%），但不比 SMA 更好；也说明大盘过滤的具体形式对结果有一定影响（与 E2a 一致）。
- 试验数累计：41

### E2c Risk-On 逐步建仓 vs 立即全量（2026-11-01）

### E8 调仓时点与容忍带（2026-11-01）
- 平滑 1 / 3 / 7 天：Calmar 1.19 / 1.47 / 1.87，最大回撤 −37.5% / −32.1% / −26.9%。
- 单一调仓日（周一～周日）：Calmar 1.35 / 1.42 / 1.97 / **3.22** / 1.85 / 1.02 / 1.22，夏普 1.28～1.98——时点运气极大（周四的 3.22 是运气，不能选）。7 日平滑消除了这种离散 ✓。
- 容忍带（卫星每月交易笔数 / 平均每笔金额 / 相对"无容忍带"的跟踪误差 / 总成本占初始资金）：
  - absolute 0.02：19.6 笔 / 91 USDT / 0.035 / 0.25；夏普 1.58、Calmar 1.71
  - relative 0.15：86.1 笔 / 34 USDT / 0.014 / 0.37；夏普 1.61
  - relative 0.25：69.9 笔 / 41 USDT / 0.024 / 0.36；夏普 1.68、Calmar 1.87
  - relative 0.40：52.9 笔 / 53 USDT / 0.039 / 0.35；夏普 1.72、Calmar 2.14
  - 无容忍带：176 笔 / 18 USDT / 0 / 0.42；夏普 1.57
- 用户的判断得到证实：绝对阈值 0.02 让卫星约 3/4 的调整被跳过（每月 20 笔对 70 笔），跟踪误差更大。各容忍带的夏普差 ≤ 0.14、两段方向不一，属于噪声 → 按预注册规则**选 relative 0.25**（跟踪误差居中、成本与 0.40 相当）。
- 结论：保留 `smoothed` 7 天与 `threshold_mode: relative`、`threshold_rel: 0.25`。
- 试验数累计：100

### E9 成本压力与真实资金量（2026-11-01）

### E10 稳健性汇总（2026-11-01，最终配置）
- walk-forward（训练 12 个月 / 测试 3 个月，9 个候选：目标波动 {0.25,0.30,0.35} × 核心权重 {0.3,0.5,0.7}）：拼接样本外年化 35.0%、夏普 1.43、最大回撤 −23.2%、Calmar 1.51（切换成本忽略）。
- block bootstrap（块长 30 天，1000 次）：回撤中位数 −25.8%，80 / 90 / 95 分位 −32.1% / −36.3% / −40.0%；回撤 ≤ 35% 的概率 87%，≤ 30% 的概率 72%。
- DSR = 0.998（试验数 107，试验夏普标准差 0.18）→ 强。注意它检验的是夏普显著大于 0，包含市场 beta。
- 结论：最终配置见 `doc/research/proposal_v1.md`。
